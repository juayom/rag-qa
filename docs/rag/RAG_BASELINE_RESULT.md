## Baseline 관찰 사항

1. **검색·재랭킹 Hit가 모두 100% (20 / 20)**
   검색 단계와 Re-ranking 단계 모두 정답 chunk를 놓치지 않았다.
   두 단계 모두 상한에 도달해 있어, 현재 질문셋만으로는 검색 방식 간 Hit 차이를 변별하기 어려울 수 있다.

2. **reranking_ms가 total의 약 66%**
   대표 7문항 평균 reranking_ms 10182.84 / total_ms 15310.58 (약 66.5%).
   후보 8건 조건인 `F-01`도 reranking 평균 7616.87ms(약 7.6초)로, 후보 수가 적은 경우에도 Re-ranking 비중이 크다.

3. **Multi Query 실행률 95.7% (22 / 23)와 retrieval_ms 차이**
   MQ를 실행한 `F-01`의 retrieval_ms는 2176.78, MQ를 실행하지 않은 `F-02`는 652.65다 (1회차 값).
   retrieval 구간 시간이 Multi Query 실행 여부에 따라 갈린다.
